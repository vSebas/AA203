\subsection*{2.2(b)}
For an \(n\)-segment grid, each route consists of \(n\) up moves and \(n\) down
moves, so exhaustive search evaluates $\boxed{\binom{2n}{n}}$ routes. 

Dynamic programming evaluates each nonterminal node. The number of DP evaluations is 
$\boxed{n(n+2)}$.

For \(n=3\), these give \(\binom{6}{3}=20\) and \(3(5)=15\).
